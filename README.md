## Mykhailo Popovych

Smart Home Engineer & Integrator based in Vilnius. Seven years of turning
buildings into systems that run themselves — lighting, climate, ventilation,
security, networking.

### What I build

**[ha-larnitech](https://github.com/mpopovych-thinkhome/ha-larnitech)** —
Home Assistant integration for Larnitech controllers over the API2
WebSocket. Local or cloud connection, multiple controllers per instance,
push updates with a safety poll, two-way control for most of the widget
catalog.

**[larnitech-mcp](https://github.com/mpopovych-thinkhome/larnitech-mcp)** —
MCP server for Larnitech installations. Reads and writes device statuses,
watches for changes, saves snapshots.

### Stack

**Platforms** — Larnitech, Home Assistant, Grenton, SVIT, KNX

**Code** — Python, C++, C#, TypeScript
**Infrastructure** — Linux, Docker, Mikrotik, UniFi, VLAN, VPN
